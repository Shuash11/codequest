# CodeQuest — download site

The landing page for the CodeQuest Windows build: https://shuash11.github.io/codequest/

- The **Download** button points at this repository's latest release asset
  (`releases/latest/download/CodeQuest-1.0.0-win-x64.zip`), so updating the app
  means uploading a new release with the same asset name — the page never
  changes.
- The package contains the self-contained app, a freshly seeded demo database,
  and the runtime configuration.

Powered by GitHub Pages (deployed from `main`).
