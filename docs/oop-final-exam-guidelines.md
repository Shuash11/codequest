FINAL EXAMINATION 
C# Object-Oriented Programming and Database Development 
Final Examination Requirement: Desktop System Development Project 
Examination Type: Project-Based Final Examination 
Total Points: 100 Points 
Development Platform: C# .NET Windows Forms (WinForms) 
Database: Relational Database Management System (MySQL, SQL Server, or SQLite) 
Programming Paradigm: Object-Oriented Programming (OOP) 
I. Project Overview 
For your final examination, you are required to design, develop, and implement a functional C# 
desktop application using the .NET Windows Forms framework. The project must be a system that 
addresses a specific problem or provides a practical solution to an identified need. 
The application must demonstrate your understanding of Object -Oriented Programming concepts, 
database design, data management, and desktop application development. 
Your system must use a relational database designed and normalized up to the Third Normal Form 
(3NF). It must also demonstrate the proper application of OOP principles, including encapsulation, 
inheritance, polymorphism, and abstraction. 
The project must be functional, user-friendly, and properly structured. You are expected to apply the 
programming and database development concepts discussed throughout the semester. 
II. Project Requirements 
The developed system must satisfy the following requirements: 
A. Functional Requirements 
The system must include the following features: 
1. Data Management (CRUD Operations) 
• Create, retrieve, update, and delete records. 
• Display records using a DataGridView or an equivalent component. 
• Implement searching and filtering of records. 
2. Database Integration 
• Use a relational database. 
• Establish a proper connection between the C# application and the database. 
• Implement appropriate primary keys and foreign keys. 
• Ensure that the database structure follows 3NF. 
• Use parameterized queries to prevent SQL injection. 
3. Object-Oriented Programming 
• Implement classes and objects. 
• Apply encapsulation through private fields and appropriate properties. 
• Demonstrate inheritance using a base class and derived classes. 
• Apply polymorphism through method overriding or interfaces. 
• Demonstrate abstraction using abstract classes or interfaces.

4. System Functionality 
• Include at least three interconnected database tables. 
• Implement at least three major functional modules. 
• Provide input validation and error handling. 
• Implement at least one report, summary, or transaction-related feature. 
5. User Interface 
• Develop a Windows Forms desktop application. 
• Provide a consistent and organized user interface. 
• Ensure that forms are easy to navigate. 
• Display appropriate messages for successful and unsuccessful operations. 
B. Suggested System Projects 
Students may choose their own system, provided that it meets the project requirements. 
1. Inventory Management System 
Manage products, categories, suppliers, stock movements, and inventory reports. 
2. Student Information System 
Manage student records, courses, enrollments, and academic information. 
3. Point-of-Sale System 
Manage products, customers, sales transactions, and transaction details. 
4. Library Management System 
Manage books, authors, borrowers, borrowing transactions, and returns. 
Other proposed systems are allowed, subject to the instructor's approval.

IV. Project Deliverables 
Students must submit the following: 
1. Complete Source Code 
• Visual Studio project files. 
• C# source code files. 
• All necessary resources and dependencies. 
2. Database Files 
• Database file or SQL database script. 
• Database tables and relationships. 
• Sample records for testing. 
• Documentation showing the database normalization up to 3NF. 
3. Project Documentation 
• System title and brief description. 
• Objectives of the system. 
• System features and functional modules. 
• Database Entity-Relationship Diagram (ERD). 
• Database normalization documentation. 
• Explanation of the OOP concepts implemented. 
4. System Demonstration 
• Students must demonstrate the actual working application. 
• Students must explain the implementation of the required OOP concepts. 
• Students must explain how their database follows 3NF. 
V. Important Guidelines

• The project may be developed individually or in pair. 
• The project must be developed using C# .NET Windows Forms. 
• The use of other programming languages for the main application is not allowed. 
• The database must be relational and normalized up to 3NF. 
• OOP concepts must be implemented in the actual source code, not merely mentioned in the 
documentation. 
• Students must be able to explain their own source code and database design. 
• Copying an existing system or submitting another student's project is strictly prohibited. 
• Students must ensure that the system runs properly during the final demonstration. 
• The instructor may conduct an individual code review or ask questions about the 
implementation.
